# PillCare Reminder

Your AI health companion for medication reminders, family care, yoga guidance and better health.

## Features
- Smart medication reminders with sound notifications
- AI-powered daily health insights and yoga recommendations
- Family/caregiver WhatsApp alerts
- Brand to generic drug resolver (OpenFDA + AI fallback)
- Weekly adherence tracking with bar charts
- Measurements, activities and mood logging
- Emergency helpline with GPS location detection
- Offline-first — works without internet, syncs in background

## Tech Stack
- **Frontend**: React Native (Expo SDK 54)
- **Backend**: FastAPI on Google Cloud Run
- **Database**: MongoDB Atlas
- **Auth**: Google Sign-In (native SDK)
