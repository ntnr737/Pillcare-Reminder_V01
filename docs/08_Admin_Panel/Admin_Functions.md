# PillCare Admin Panel - Operational Procedures & Manual Controls

## 1. Upgrade User Plan Manually
1. Log into `admin.pillcare.in`.
2. Scroll to **2-Way User Feature Overrides** table.
3. Locate Target User ID.
4. Select desired plan (`pro` / `enterprise`) and duration (`30 days`).
5. Click **Apply Upgrade**. Backend immediately updates user record; mobile app reflects new plan limits on next feature sync (`/api/me/features`).

---

## 2. Publish Swiggy/Zomato Flash Offer
1. Open **Flash Announcement Publisher** section.
2. Fill Title: `⚡ Special 50% Off Annual Moksha Pro`.
3. Select Target Audience: `Free Users`.
4. Enter Link URL: `https://pillcare.in/upgrade`.
5. Click **Publish Announcement Live**. Banner immediately appears at the top of the Today screen for all Free plan mobile users.
