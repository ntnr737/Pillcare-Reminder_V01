# PillCare - User Acceptance Testing (UAT) Checklist

## 1. Senior Patient Usability Validation
- [x] **Large Text Visibility**: Text sizes legible without reading glasses ($\ge 18\text{sp}$).
- [x] **Touch Target Precision**: Buttons easily tappable ($\ge 48\text{dp}$ touch bounding box).
- [x] **Audio Alarm Clarity**: High-pitch wellness audio alerts audible across room noise.
- [x] **1-Tap Take Action**: Single tap marks medication as taken with instant haptic confirmation.

---

## 2. Offline Resilience Validation
- [x] **Airplane Mode Verification**: Turn on Airplane mode $\rightarrow$ Alarms fire on time $\rightarrow$ Dose logged locally $\rightarrow$ Syncs automatically upon network reconnection.
