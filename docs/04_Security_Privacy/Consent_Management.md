# PillCare - Consent Management Matrix

## 1. User Consent Options & Default States

| Consent Scope | Description | Default State | Opt-Out Impact |
| :--- | :--- | :---: | :--- |
| **Caregiver Escalation** | Permission to dispatch missed-dose notifications to caregiver WhatsApp/SMS. | **OPT-IN (Required)** | Caregiver Shield notifications disabled. |
| **Health Telemetry** | Sync adherence statistics to cloud for Healthcare Intelligence Radar. | **OPT-IN (Default)** | Adherence trends visible only on local device. |
| **Flash Announcements** | Display promotional banners (e.g. Swiggy/Zomato partner offers). | **OPT-IN (Default)** | Banner area hidden on Today tab. |
| **Health Connect Integration** | Sync vitals (Blood pressure, glucose) from native HealthKit/Health Connect. | **OPT-OUT (Explicit Grant)** | Vitals must be logged manually. |
