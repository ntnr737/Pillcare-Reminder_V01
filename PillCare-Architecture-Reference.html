2. End-to-End Integration Contracts & Protocols

A. Subscription Tiers & 1-Click Feature Override Engine

Admin Panel updates subscription plans (Free, Basic ₹30, Premium ₹99, Enterprise) and billing cycles (Monthly 30d, Annual 365d) or toggles specific features (OCR Scanner, PDF Export, Yoga Full, Brand → Generic, Caregiver Alerts).

POST /admin/users/{user_id}/subscription — Set subscription plan, billing cycle, expiration, and notes.

POST /admin/users/{user_id}/features — Apply single-click feature overrides (export_data, scanner, yoga_full, etc.).

DELETE /admin/users/{user_id}/features/{feature} — Remove a manual feature override.

GET /api/me/features — Mobile client endpoint to sync active user privileges.

B. High-Reliability Push Notification Pipeline

Supports both ExpoPushToken[...] and ExponentPushToken[...] formats across Expo SDK versions.

POST /api/profile/push-token — Registers or updates device push token (accepts { push_token } or { token }).

POST /admin/notify — Broadcasts push notifications globally or to specific target user_id / email.

C. Flash Announcements & Healthcare Intelligence

Allows broadcasting instant in-app promotions, system alerts, or feature releases to specific subscription tiers.

POST /admin/announcements — Publish announcement (title, body, type, target_plan, link_url).

GET /admin/analytics/financials — Unit economics (MRR, ARR, ARPU, LTV, Paid Conversion %).

GET /admin/analytics/healthcare-intelligence — Refill GMV, Low-Stock Radar (≤3 doses remaining).

4. Performance & Concurrency Rules

    Concurrent Batch Aggregation (asyncio.gather): All admin endpoints returning user lists or analytics avoid sequential for loop queries, processing database queries concurrently to maintain sub-50ms latency. FastAPI Static Route Order: Static endpoints (e.g. /admin/analytics/users/comprehensive) are declared before parameterized endpoints (e.g. /admin/analytics/users/{user_id}) to prevent route matching collisions. Authentication Enforcer: require_admin dependency validates header x-admin-secret matching ADMIN_SECRET environment variable or valid Google OAuth admin tokens.
